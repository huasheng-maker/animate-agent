# 激光雷达与路径规划：手工教学设计

本例先验证教学模型，再讨论自动生成。目标：学习者能区分测距与地图、解释机器人半径为何改变可行路线，并通过封路实验证明“没有路径”也是正确结果。

| 拍 | 问题 | 必须可见的变化 | 可核验的知识 |
|---|---|---|---|
| 1 / 0–4 秒 | 雷达真正测到了什么？ | 360° 射线依次出现，首个表面回波亮起 | 每束只有最近交点；遮挡后方不等于空地 |
| 2 / 4–8 秒 | 中心能过去，车身就能过去吗？ | 障碍周围出现安全禁区 | 圆盘机器人半径 + 余量 + 保守栅格修正影响通行 |
| 3 / 8–12 秒 | 绕哪边走？ | 按实际顺序展开 A* 已访问格，再显示路线 | 四邻接、单位边代价、曼哈顿启发式；无可行解时不画假路线 |
| 4 / 12–24 秒 | 这条路线真的能走吗？ | 机器人按已求解的路径行驶，雷达随车重新测距 | 路径连续段满足净空；本例忽略加速度与转弯半径 |

交互实验：移动中间货架；增大机器人半径；调整安全余量；缩短测距范围；切换窄门/封路环境；比较完整已知地图与仅单帧观测。每次实验暂停并回到相关教学拍，重新计算，避免沿旧路线继续移动。

建模边界：默认有先验静态地图，雷达显示当前测量，不声称一帧扫描重建了整张地图。仅单帧模式从射线穿过的格构建 free，从命中格构建 occupied，其余 unknown 都禁止通行；不做 SLAM、探索、动态障碍预测、真实 Nav2 集成。无路含义依模式不同：已知地图中无满足约束的路径，或单帧证据不足以证明通路。

视觉约定：青色=测量/回波，珊瑚色=实物障碍，琥珀色=膨胀禁区，蓝色=搜索访问格，绿色=已求出的路线。采用现有 Remotion Player、AnimationIR Timeline Runtime、Canvas renderer 和 body 图元，补充领域专用栅格/测距覆盖层；不引入新图形引擎。
